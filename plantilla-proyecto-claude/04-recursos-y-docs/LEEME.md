# Recursos y documentación de referencia

Acá van papers, specs, manuales largos, capturas de logs extensos, documentación de una API externa, etc.

**Regla clave:** nada de esta carpeta se sube como conocimiento fijo del Proyecto de Claude. Se adjunta puntualmente en la conversación donde realmente se necesita, y solo esa vez. Así el proyecto no arrastra tokens de documentos que no se usan en el 90% de las charlas.

Si un fragmento de acá se vuelve relevante de forma permanente (por ejemplo, una convención que vas a reusar siempre), resumilo en 2-3 líneas y movelo a `02-proyecto-activo/decisiones-tecnicas.md` o `especificacion.md` — no subas el documento completo al conocimiento base.
